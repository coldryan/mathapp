改咗乜 · What was changed

  1. 原圖 72×72 包成 160×110 畫布 — rewrapped into a 160×110 canvas.
  2. 置中放大 1.25 倍(translate(35,10) scale(1.25))— centred and scaled 1.25×.
  3. 加咗陰影(feDropShadow dy=3 stdDeviation=2,黑色 16%)— drop shadow added.
  4. 線色由 #000000 改做 #263238 —— 46 個入面得 27 個適用 (其餘原圖冇黑線);下面個表逐個標返。Applies to 27 of 46 icons.

每個 SVG 檔頭都有 XML comment,只列返嗰個檔真正適用嘅改動。 Every file carries its own notice listing only the changes that apply to it.
