# OpenMoji — adapted icons (MathApp)

These are **adaptations** of [OpenMoji](https://openmoji.org) icons, used as object
icons in the MathApp learning app.

- **Original work**: OpenMoji — the open-source emoji and icon project
- **Original author**: OpenMoji contributors
- **Original licence**: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- **These adaptations**: also licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

## What was changed

Every icon here was modified from the OpenMoji original in the same way:

1. Rewrapped from the original `72x72` viewBox into a `160x110` canvas.
2. Centred and scaled up 1.25x (`translate(35,10) scale(1.25)`).
3. A drop shadow added (`feDropShadow dy=3 stdDeviation=2, black @ 16%`).
4. Line colour changed from `#000000` to `#263238` — this one applies to
   27 of the 46 icons (the others had no black line to recolour).
   The "Recoloured" column below says which.

Each file carries its own notice as an XML comment at the top, listing only the
changes that actually apply to that file.
